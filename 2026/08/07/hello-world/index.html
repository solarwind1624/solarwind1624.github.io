欢迎来到我的博客！这是用 Hexo + Butterfly 主题 搭建、托管在 GitHub Pages 上的第一篇文章。

为什么用静态博客

  • 免费：GitHub Pages 提供托管、HTTPS 和全球 CDN，零成本
  • 简单：用 Markdown 写作，hexo new 新建文章即可
  • 可控：源码和内容都在自己手里，可随时迁移

常用命令

接下来

  • 替换站点标题和作者信息（_config.yml）
  • 配置导航栏、头像、社交链接（_config.butterfly.yml）
  • 绑定自定义域名（可选）
  • 接入 Giscus 评论系统

这只是一个开始，慢慢把这里变成自己的小角落吧。 ✨
